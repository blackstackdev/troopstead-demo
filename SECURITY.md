# Fictional demo privacy

Use invented information only. No authentication or trusted cloud audit system exists in this demo; local storage is controlled by the browser user. Do not use it for real youth records, safeguarding information, private contacts or money handling.

Do not attach real records, credentials or private screenshots to public issues. For a potential vulnerability, use GitHub’s private vulnerability reporting option if available. If it is unavailable, open an issue asking for a private reporting channel without including exploit details, real records or secrets. No response deadline is promised.

The supplied checker detects selected credential/endpoint patterns and excluded file types. It is not a comprehensive security audit. Review the exact artifact/history and visuals before any publication. Never connect the demo to production or copy private exports into it.
