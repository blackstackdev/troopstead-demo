# Contributing to the fictional demo

This demo is released under MIT. By submitting a contribution, you agree that your contributed original work may be distributed under this repository's MIT licence. Contribute only material you have the right to share.

Run `npm test` and `npm run check` with Node 22 or newer, then verify the fictional planner → meeting → attendance → individual review → export journey. Keep inputs fictional. Changes must not add operational source, production connections, real youth records or third-party reference material. Add meaningful tests for changes to rules or storage.

Use GitHub issues for general feedback and pull requests for proposed changes. Do not include real records, private screenshots or credentials. No service level, issue-response deadline or feature-delivery promise is established.
